How every lesson works

  • Find the flag. Each lesson hides one letter you can only find by using the new skill.
  • Hints if you want them. A lantern gives up to three: a nudge, the tool, then the exact steps. Finish without any for a ★.
  • Pinned to a version. Keys and manual links match the exact version you use, and older versions stay online.
