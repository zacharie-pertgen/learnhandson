# Blender on Signal Island: Lesson Outline (v0.2)

**Status:** draft for Macs to review. Nothing is built yet.
**Three tiers**, each about 60 minutes with 6 lessons and one flag word:
- **Tier 1: Intro, "Relight the Beacon"** → BEACON (fully detailed below)
- **Tier 2: Intermediate, "The Lantern's Reach"** → KEEPER (plan level, section 4b)
- **Tier 3: Advanced, "Into the Squall"** → SIGNAL (plan level, section 4c)
- Each tier can be started on its own with a provided starter scene. Doing them in order tells the full story.
**Routes:** every lesson works in both
- **Sim**: the in-browser Three.js viewport (the app detects your action)
- **Companion**: real Blender open beside the app (you find the flag and type it in)

---

## 1. Key terms

- **Viewport**: the 3D window where you look at and edit the scene.
- **Object Mode / Edit Mode**: Object Mode moves whole objects. Edit Mode changes an object's shape (its vertices, edges, faces).
- **Keymap**: the list of which key does what. Lessons use Blender's default keymap with left-click select.
- **LTS**: Long Term Support release. Blender keeps it stable and patched for 2 years, so lessons pinned to it stay correct longer.
- **Flag**: the hidden letter each lesson asks you to find.

---

## 2. The theme: Signal Island

An original story that runs through every lesson.

- **Setup:** You are the new keeper of Signal Island, a tiny floating island whose beacon guides ships through the fog. Last night a storm scattered the beacon's six signal flags across the island.
- **Each lesson:** a short scene on the island with one flag hidden somewhere. You can only find it by using that lesson's new skill. Each flag carries one letter.
- **The payoff:** the six letters spell **B E A C O N**. In Lesson 6 you build a new beacon tower, enter the word, and the beacon lights up the fog.
- **Tone:** cozy, low-poly, a little mysterious. A narrator voice ("the Old Keeper") gives one line of story per lesson, then gets out of the way.

**Why a letter per flag works for both routes**
- Sim: the app detects the action, and the flag animates into view.
- Companion: the flag is really in the scene file, so the only way to get the letter is to do the skill in Blender. Typing the letter is the self-check, and the app can verify it.

**Series tie-in:** Signal Island is one island in **the Lantern Isles**, the shared world for every program in the series. See [archipelago.md](archipelago.md).
- The fog around the island is **the Fog**, the series-wide enemy, and the storm is the **Grey Squall** that breathes it out.
- The beacon is **Signal Island's lantern**. Relighting it clears the Fog around the island on the world map.
- BEACON is this island's word. It lights up Signal Island on the Quillfish's world map, and it counts toward the series finale.
- **Light references** (story text only, the lessons work on their own):
  - Lesson 2: the oil barrel is stamped "Property of the Quillfish".
  - Lesson 3: the flagpole's rope came from the Harbor's ropewalk.
  - Lesson 6 finale: the Quillfish sails past the new light toward the Harbor (the Git island). The Old Keeper adds one line: "The light didn't go out on its own. Someone at the Tide Archive will know more." This sets up the SQL island.

**Optional hints (every lesson):** a lantern button opens up to 3 hints, one at a time. Hints are never forced.
- **Hint 1, Nudge:** a story-voice clue about where to look or what to think about.
- **Hint 2, Specific:** names the tool or key to use.
- **Hint 3, Answer:** the exact steps (and, in the sim, a short animated demo of the key presses).
- **Smart offer:** the sim gently pulses the lantern if you've been stuck about 90 seconds or tried the wrong thing 3 times. It never opens a hint by itself.
- **No penalty:** you still get the flag. The finale just shows "found with 0 / 3 / 7 hints" for fun, and a star for each lesson finished hint-free.
- **Wrong-answer hints:** a wrong letter or count gets a targeted reply (for example "That's a P? Try looking from directly above"), so a mistake becomes a hint.

**Starter files (Companion route):** each lesson ships a small `.blend` file of its island scene, generated by a Python script (see section 6). The Prologue and Lesson 6 can also use Blender's default startup scene.

## 4. Tier 1: Intro lessons

### Lesson 0. Prologue: Arrive on the island (3 min)

**Goal:** know the four main areas and set up your input device.

**Concepts**
- 3D Viewport, Outliner (list of objects), Properties (settings), Timeline
- Toolbar (left) and Sidebar (right)
- Status bar at the bottom shows what each mouse button does right now

**Keybinds**
- `T` toggle Toolbar
- `N` toggle Sidebar
- `Ctrl Z` undo, `Ctrl Shift Z` redo

**Tasks**
1. Hover each area as the app highlights it.
2. Press `N` to open the Sidebar, then `N` again to close it.
3. Laptop or trackpad only: open Edit > Preferences > Input, turn on **Emulate 3 Button Mouse** and **Emulate Numpad**.

**Success check**
- Sim: `N` pressed twice (sidebar opened and closed).
- Companion: "Can you see the Item tab in the Sidebar?" yes/no. Device question picks the right key hints for later lessons (mouse, trackpad, no numpad).

**Hints**
1. Nudge: "The Sidebar hides on the right edge of the viewport."
2. Specific: "Hover over the viewport first, then press N."
3. Answer: "Move your mouse over the 3D view, press N once to open, once to close. If nothing happens, click the viewport and try again."

### Lesson 1. Find your bearings (9 min) → Flag **B**

**Story:** "The first flag is painted on the rocks, but only a gull flying straight overhead could read it."

**Goal:** move the view freely, then snap to exact views.

**Concepts**
- Orbit, pan, zoom
- Front, right, top views
- Perspective vs orthographic (orthographic removes depth distortion)

**Keybinds**
- Orbit: `Middle mouse drag`
- Pan: `Shift + Middle mouse drag`
- Zoom: `Mouse wheel` or `Ctrl + Middle mouse drag`
- Front / Right / Top: `Numpad 1` / `Numpad 3` / `Numpad 7`
- Opposite side (back, left, bottom): `Ctrl + Numpad 1/3/7`
- Toggle perspective/orthographic: `Numpad 5`
- Frame selected: `Numpad .`
- Frame everything: `Home`
- View pie menu: `` ` `` (backtick, the key left of 1)
- No middle mouse or numpad: drag the navigation gizmo (top right), or use the backtick pie

**Tasks**
1. Orbit all the way around the island.
2. Pan to the lighthouse rock and zoom in.
3. Press `Home` to see everything again.
4. Snap to Top view (`Numpad 7`).
5. Notice the scattered stones almost form a shape. Switch to orthographic (`Numpad 5`).
6. The stones line up into the letter. That is the flag.

**Puzzle design:** stones sit at different heights, so they only line up into a "B" from directly above in orthographic. From any other angle they look like random rocks.

**Success check**
- Sim: detect orbit of at least 90 degrees total, a pan, a zoom, then camera in top view and orthographic. Flag animates in.
- Companion: type the letter you see. App checks "B".

**Hints**
1. Nudge: "A gull reads these rocks. Where does a gull fly?"
2. Specific: "Use Top view (Numpad 7, or click the blue Z on the gizmo). Still blurry? Perspective is bending it."
3. Answer: "Press Numpad 7, then Numpad 5 for orthographic. The stones form the letter B."

**Manual:** [Navigation](https://docs.blender.org/manual/en/5.2/editors/3dview/navigate/navigation.html) · [Viewpoint](https://docs.blender.org/manual/en/5.2/editors/3dview/navigate/viewpoint.html)

### Lesson 2. Clear the wreckage (8 min) → Flag **E**

**Story:** "The storm dumped a pile of crates on the second flag. Clear them, but keep the barrel of lamp oil."

**Goal:** select exactly what you mean, then add, copy, and delete objects.

**Concepts**
- Active object vs selected objects (the active one is brighter)
- Selecting in the viewport vs the Outliner
- Adding new objects at the 3D cursor

**Keybinds**
- Select: `Left click`
- Add to / remove from selection: `Shift + Left click`
- Select all: `A`
- Select none: `Alt A`
- Invert selection: `Ctrl I`
- Box select: `B` (or drag on empty space with the Select Box tool)
- Circle select: `C` (wheel changes size, `Right click` or `Esc` to finish)
- Delete: `X` (asks to confirm) or `Delete` (no confirm)
- Add object menu: `Shift A`
- Duplicate: `Shift D`

**Tasks**
1. Click one crate. Shift-click two more.
2. Press `Alt A` to clear.
3. Click the oil barrel, then `Ctrl I` to select everything except it.
4. Shift-click the island ground and the lighthouse to remove them from the selection (only crates left).
5. Delete the crates. The flag is underneath.
6. Bonus: `Shift A` > Mesh > UV Sphere to add a buoy, then `Shift D` to place a second one.

**Success check**
- Sim: all crates deleted, barrel and island still exist. Flag "E" revealed.
- Companion: type the letter on the flag. If the barrel was deleted too, the app hints "Undo with Ctrl Z, the oil is needed for Lesson 6."

**Hints**
1. Nudge: "It's easier to pick what to keep than to pick every crate."
2. Specific: "Select the barrel, then flip the selection with Ctrl I. Shift-click to drop the ground and lighthouse."
3. Answer: "Click the barrel, Ctrl I, Shift-click the ground and the lighthouse, then press X and confirm. Read the letter on the flag."

**Manual:** [Selecting objects](https://docs.blender.org/manual/en/5.2/scene_layout/object/selecting.html) · [Default keymap](https://docs.blender.org/manual/en/5.2/interface/keymap/blender_default.html)

### Lesson 3. Raise the flagpole (10 min) → Flag **A**

**Story:** "The third flag is still tied to its pole, which is lying face down in the sand. Stand it back up."

**Goal:** move, rotate, and scale with axis locks and typed numbers.

**Concepts**
- Transform = location, rotation, scale
- Axis constraints (X red, Y green, Z blue)
- Typing exact values while transforming
- Reading values in the Sidebar's Item tab

**Keybinds**
- Move / Rotate / Scale: `G` / `R` / `S`
- Lock to an axis: press `X`, `Y`, or `Z` after G/R/S
- Lock out one axis (use the other two): `Shift X/Y/Z`
- Type a number, then `Enter` to confirm. `Esc` or `Right click` cancels.
- Reset location / rotation / scale: `Alt G` / `Alt R` / `Alt S`
- Adjust last operation panel: `F9`

**Tasks**
1. Select the pole. Press `N` to watch its values.
2. `R` `X` `90` `Enter` to stand it up. The cloth was face down, so the letter now faces you.
3. `G` `Z` then drag it until it sits on the sand.
4. It is too short. `S` `1.5` `Enter`.
5. Oops test: press `G`, move, then `Right click` to cancel. Nothing moved.
6. Press `F9` after a rotate and change the angle there.

**Success check**
- Sim: pole rotation X is 90 degrees (within 2), scale is 1.5, bottom at ground height (within a small margin). Flag unfurls.
- Companion: type the letter, plus a second check: "What does the Sidebar show for Rotation X?" Expect 90.

**Hints**
1. Nudge: "The pole tipped over sideways along the red line."
2. Specific: "Rotate (R) locked to the X axis, and type the angle instead of dragging."
3. Answer: "Select the pole, press R, X, type 90, Enter. Then G, Z to set it on the sand, and S, 1.5, Enter."

**Manual:** [Transform](https://docs.blender.org/manual/en/5.2/scene_layout/object/editing/transform/index.html) · [Axis locking](https://docs.blender.org/manual/en/5.2/scene_layout/object/editing/transform/control/axis_locking.html)

### Lesson 4. Inside the boulder (8 min) → Flag **C**

**Story:** "Something glints inside the big boulder. The fourth flag is not painted on it, it is hidden inside it."

**Goal:** switch to Edit Mode and pick vertices, edges, and faces.

**Concepts**
- A mesh is made of vertices (points), edges (lines), faces (surfaces)
- Select modes
- Edge loops (a ring of connected edges)
- X-ray lets you see and select through the surface

**Keybinds**
- Toggle Edit Mode: `Tab`
- Mode pie menu: `Ctrl Tab`
- Vertex / Edge / Face select mode: `1` / `2` / `3` (top number row, in Edit Mode)
- Loop select: `Alt + Left click` on an edge
- Toggle X-ray: `Alt Z`
- Shading pie: `Z`
- Hide / reveal: `H` / `Alt H`

**Tasks**
1. Select the boulder, press `Tab`.
2. Press `1`, `2`, `3` and click a vertex, an edge, a face in each.
3. `Alt + click` an edge to grab a whole loop.
4. Turn on X-ray (`Alt Z`) in vertex mode. A cluster of vertices floats inside the boulder.
5. Orbit until the cluster reads as a letter.

**Puzzle design:** loose vertices inside the mesh form a "C". They only show in Edit Mode, and only clearly with X-ray on.

**Success check**
- Sim: in Edit Mode, each select mode used once, one loop select, X-ray on. Flag glows.
- Companion: type the letter.

**Hints**
1. Nudge: "The glint isn't on the surface. You need to see through stone, and see the points it's made of."
2. Specific: "Be in Edit Mode, vertex select (1), and turn on X-ray."
3. Answer: "Select the boulder, Tab, press 1, then Alt Z. Orbit to face the front (Numpad 1). The dots inside form the letter C."

**Manual:** [Mesh selecting](https://docs.blender.org/manual/en/5.2/modeling/meshes/selecting/introduction.html) · [Select loops](https://docs.blender.org/manual/en/5.2/modeling/meshes/selecting/loops.html) · [Shading and X-ray](https://docs.blender.org/manual/en/5.2/editors/3dview/display/shading.html)

### Lesson 5. Hollow the lantern (10 min) → Flag **O**

**Story:** "The beacon needs a lantern box. The fifth flag was sealed inside the old one when it was cast."

**Goal:** change shape with the four core modeling tools.

**Concepts**
- Extrude pulls new geometry out of a selection
- Inset makes a smaller face inside a face
- Loop cut adds a ring of edges for more detail
- Bevel rounds sharp edges

**Keybinds** (Edit Mode)
- Extrude: `E` (then `Z` to lock, or type a distance)
- Inset: `I` (press `I` again for individual faces)
- Loop cut: `Ctrl R` (wheel sets number of cuts, click to place, then slide)
- Bevel: `Ctrl B` (wheel sets segments)

**Tasks**
1. Select the lantern box, `Tab`, face mode `3`.
2. Select the top face. `I`, type `0.2`, `Enter`.
3. `E`, type `-0.8`, `Enter` to push the face down. The box is now hollow.
4. Look inside. The flag was sealed in there.
5. `Ctrl R` on a side to add a band around the middle.
6. Select the top rim edges and `Ctrl B` with 2 segments for a softer edge.

**Success check**
- Sim: inset and inward extrude on the top face (face count grows by 8, inner face lower than rim). Loop cut and bevel detected as bonus stars.
- Companion: type the letter. Bonus: turn on Overlays > Statistics and enter the face count (the app knows the expected numbers with and without the bonus steps).

**Hints**
1. Nudge: "To get inside a box without breaking it, make a rim first, then dig down."
2. Specific: "Inset (I) the top face, then extrude (E) with a negative number."
3. Answer: "Face mode 3, click the top face, I, 0.2, Enter, then E, -0.8, Enter. Orbit to look down inside."

**Manual:** [Extrude](https://docs.blender.org/manual/en/5.2/modeling/meshes/editing/mesh/extrude.html) · [Inset Faces](https://docs.blender.org/manual/en/5.2/modeling/meshes/editing/face/inset_faces.html) · [Loop Cut](https://docs.blender.org/manual/en/5.2/modeling/meshes/tools/loop.html) · [Bevel](https://docs.blender.org/manual/en/5.2/modeling/meshes/editing/edge/bevel.html)

### Lesson 6. Build the beacon (12 min) → Flag **N**

**Story:** "Five flags found. The last one is not hidden anywhere. It appears when the island has a beacon again."

**Goal:** build a simple beacon tower from Blender's default cube, with no step-by-step key hints unless asked.

**Build steps** (hints hidden behind a "Show me" button)
1. Start with the default cube. `Tab`, face mode `3`.
2. Select the top face. `E` `Z` `1.5` `Enter` (taller tower).
3. `I` `0.2` `Enter` (a rim).
4. `E` `-0.3` `Enter` (a recess for the lamp).
5. `Ctrl R` around the middle of the tower, one cut, click twice to place it centered.
6. `Tab` back to Object Mode. `Shift A` > Mesh > UV Sphere.
7. `S` `0.3` `Enter`, then `G` `Z` to set it in the recess.

**Self-checking math:** after steps 2 to 5, the tower has exactly **24 vertices and 22 faces**. (Cube 8/6, extrude +4/+4, inset +4/+4, extrude +4/+4, loop cut +4/+4.)

**Success check**
- Sim: tower mesh has 22 faces, a sphere exists near the top of it. The sixth flag drops onto the tower.
- Companion: turn on Overlays > Statistics, select the tower, enter its face count. "22" unlocks the flag "N". Wrong numbers get a specific hint (for example 18 means the loop cut is missing).
- Finale (both routes): enter all six letters. BEACON relights the beacon (Signal Island's lantern), the Fog rolls back from the island, the Quillfish sails past toward the Harbor. Show total time and a "share your beacon" screenshot prompt.

**Hints** (per build step, plus for the count)
1. Nudge: "Taller first, then a rim, then a dip for the lamp. Every step is a skill you already found a flag with."
2. Specific: names the tool for the step you're stuck on (Extrude, Inset, Loop cut, Add mesh).
3. Answer: shows that step's exact keys from the build list above.
- **Count hints:** 18 faces means one step is missing. Check from the side for the middle band (loop cut), then look down for the lamp dip (recess extrude). 14 means two steps are missing. Any other number suggests Ctrl Z back a step or restart from a fresh cube.

**Manual:** [Overlays (Statistics)](https://docs.blender.org/manual/en/5.2/editors/3dview/display/overlays.html) · [Adding objects](https://docs.blender.org/manual/en/5.2/scene_layout/object/types.html)

## 4b. Tier 2: Intermediate, "The Lantern's Reach" (about 60 min) → word **KEEPER**

**Story:** The beacon is lit, but its beam only reaches the shore. The Old Keeper names you their apprentice, and together you rebuild the cottage, the dock, and the lantern's lens so the light can reach the next island.
**Lantern payoff:** the beam reaches across the sea. On the world map, a clear sea lane opens toward the Harbor.
**Starts from:** the finished Intro scene (or a provided starter file).
**Detail level:** plan. Full step lists, hints, and checks get written when this tier is built.

| # | Lesson | Time | New skills | Flag |
|---|---|---|---|---|
| 1 | Re-lay the stone steps | 10 min | 3D cursor, pivot point, snapping | **K** |
| 2 | Reshape the dunes | 8 min | Proportional editing | **E** |
| 3 | Patch the rowboat | 10 min | Mirror and Subdivision Surface modifiers | **E** |
| 4 | Rebuild the pier | 10 min | Array and Solidify modifiers | **P** |
| 5 | Color the lantern glass | 10 min | Materials, Principled BSDF, emission, Material Preview | **E** |
| 6 | Restore the keeper's cottage | 12 min | Parent, join, collections, apply transforms (mini project) | **R** |

### Lesson plans

**1. Re-lay the stone steps → K**
- **Keys:** place 3D cursor `Shift + Right click`, Snap menu `Shift S`, pivot pie `.` (period), snapping toggle `Shift Tab`, hold `Ctrl` while moving to snap.
- **Flag puzzle:** the stair stones only fit when snapped edge to edge. Once all snap into place, their tops form a "K".
- **Check:** Sim: every stone snapped to its slot. Companion: type the letter.
- **Hints:** Nudge "Stones fit better when they stick." Specific "Turn on snapping with Shift Tab." Answer: exact snap target and keys.
- **Manual:** [3D cursor](https://docs.blender.org/manual/en/5.2/editors/3dview/3d_cursor.html) · [Pivot point](https://docs.blender.org/manual/en/5.2/editors/3dview/controls/pivot_point/index.html) · [Snapping](https://docs.blender.org/manual/en/5.2/editors/3dview/controls/snapping.html)

**2. Reshape the dunes → E**
- **Keys:** proportional editing `O`, mouse wheel changes the falloff radius while moving.
- **Flag puzzle:** pulling one vertex up with the right radius lifts a sand mound. When it reaches the marked height, wind uncovers an "E" in the sand.
- **Check:** Sim: one vertex at target height, nearby vertices raised by falloff. Companion: type the letter.
- **Hints:** Nudge "Pull one grain and the whole dune should follow." Specific "Turn on proportional editing (O) before G Z." Answer: exact steps and radius.
- **Manual:** [Proportional editing](https://docs.blender.org/manual/en/5.2/editors/3dview/controls/proportional_editing.html)

**3. Patch the rowboat → E**
- **Keys:** Properties > Modifiers > Add Modifier, `Ctrl 1/2/3` to add Subdivision at that level (Object Mode), Shade Smooth from the right-click menu.
- **Flag puzzle:** half a boat hull. Add Mirror to complete it. Add Subdivision to smooth it. The letter appears on the bow only after both, in the right order.
- **Check:** Sim: modifier stack is Mirror then Subdivision. Companion: type the letter, plus "How many modifiers are in the stack?" (2).
- **Hints:** Nudge "Only half the boat washed ashore. What if it had a twin?" Specific "Mirror first, then Subdivision." Answer: exact clicks.
- **Manual:** [Modifiers](https://docs.blender.org/manual/en/5.2/modeling/modifiers/introduction.html) · [Mirror](https://docs.blender.org/manual/en/5.2/modeling/modifiers/generate/mirror.html) · [Subdivision Surface](https://docs.blender.org/manual/en/5.2/modeling/modifiers/generate/subdivision_surface.html)

**4. Rebuild the pier → P**
- **Keys:** Array modifier (count, relative offset), Solidify modifier (thickness), `Ctrl A` > Apply to make a modifier real.
- **Flag puzzle:** one plank exists. Array it into the right count (12) to reach the post where the flag hangs. Solidify the thin planks so the pier "holds weight" and you can walk to it.
- **Check:** Sim: array count 12, solidify thickness above 0. Companion: type the letter, plus the plank count.
- **Hints:** Nudge "One good plank is all you need, then copy it." Specific "Array modifier, count 12." Answer: exact values.
- **Manual:** [Array](https://docs.blender.org/manual/en/5.2/modeling/modifiers/generate/array.html) · [Solidify](https://docs.blender.org/manual/en/5.2/modeling/modifiers/generate/solidify.html)

**5. Color the lantern glass → E**
- **Keys:** Material Preview shading via `Z` pie, Material tab > New, Principled BSDF Base Color and Emission Strength.
- **Flag puzzle:** the lantern glass is clear. Give it an amber emissive material and the light projects an "E" onto the cottage wall (a cut-out pattern in the lantern frame).
- **Check:** Sim: glass material with emission strength above 0 and warm hue. Companion: type the letter.
- **Hints:** Nudge "Glass that glows would throw a shadow pattern." Specific "Emission Strength in the Principled BSDF." Answer: exact values (for example hex `#FFB347`, strength 5).
- **Manual:** [Materials](https://docs.blender.org/manual/en/5.2/render/materials/introduction.html) · [Principled BSDF](https://docs.blender.org/manual/en/5.2/render/shader_nodes/shader/principled.html)

**6. Restore the keeper's cottage → R (mini project)**
- **Keys:** parent `Ctrl P`, clear parent `Alt P`, join `Ctrl J`, separate `P` (Edit Mode), move to collection `M`, apply transforms `Ctrl A`.
- **Build:** walls from a cube (Mirror for symmetry), roof via extrude and scale, chimney parented to the roof, door and window joined into one "Trim" object, everything in a "Cottage" collection, scale applied.
- **Check:** Sim and Companion: the app asks for 3 facts it can verify (number of objects in the Cottage collection, the chimney's parent's name, the roof's scale after apply, which should read 1). All 3 correct unlocks "R".
- **Finale:** enter KEEPER. The Old Keeper hands you the keeper's key, the beam reaches across the sea, and a lane through the Fog opens toward the Harbor.
- **Manual:** [Parenting](https://docs.blender.org/manual/en/5.2/scene_layout/object/editing/parent.html) · [Join](https://docs.blender.org/manual/en/5.2/scene_layout/object/editing/join.html) · [Collections](https://docs.blender.org/manual/en/5.2/scene_layout/collections/collections.html) · [Apply](https://docs.blender.org/manual/en/5.2/scene_layout/object/editing/apply.html)

## 4c. Tier 3: Advanced, "Into the Squall" (about 60 min) → word **SIGNAL**

**Story:** The Grey Squall notices the light and sends a wall of Fog straight at Signal Island. Your beam needs to cut through it. You map, carve, scatter, light, and animate the lighthouse until its turning beam is strong enough to push the Fog back.
**Lantern payoff:** a rotating beam that pierces the Fog around the Squall. On the world map, it lights the first stretch of the route toward the Eye of the Squall.
**Starts from:** a provided lighthouse scene (so Advanced can be taken without Intermediate).
**Detail level:** plan.
**Route note:** Advanced is **companion-first**. Sculpting, nodes, and rendering are too heavy to simulate fully in a browser, so the sim offers a lighter "concept" version of lessons 2 to 4 (described below) and the real-Blender route gets the full experience.

| # | Lesson | Time | New skills | Flag |
|---|---|---|---|---|
| 1 | Map the lighthouse banner | 10 min | UV seams, unwrapping, UV editor, image texture | **S** |
| 2 | Carve the sea cliffs | 10 min | Sculpt Mode basics, brushes, radius and strength | **I** |
| 3 | Scatter the guide stones | 10 min | Geometry Nodes: distribute points, instance on points | **G** |
| 4 | Stage the night scene | 10 min | Camera, lights, Eevee vs Cycles, render | **N** |
| 5 | Turn the beam | 10 min | Keyframes, timeline, playback, Graph Editor easing | **A** |
| 6 | The lighthouse signal | 10 min | Everything: render a short animation (final project) | **L** |

### Lesson plans

**1. Map the lighthouse banner → S**
- **Keys:** Edit Mode edge select, mark seam via `Ctrl E` > Mark Seam (or `U` menu), unwrap `U` > Unwrap, UV Editing workspace tab.
- **Flag puzzle:** a banner wraps the tower, but its painted texture is scrambled. Mark the right seam and unwrap, and the texture lines up to show an "S".
- **Check:** Sim: seam on the correct edge loop, UV island unwrapped. Companion: type the letter.
- **Hints:** Nudge "A banner has to be cut somewhere to lie flat." Specific "Mark a seam down the back, then unwrap." Answer: exact edge and keys.
- **Manual:** [UV unwrapping](https://docs.blender.org/manual/en/5.2/modeling/meshes/uv/unwrapping/introduction.html) · [Seams](https://docs.blender.org/manual/en/5.2/modeling/meshes/uv/unwrapping/seams.html)

**2. Carve the sea cliffs → I**
- **Keys:** Sculpt Mode via `Ctrl Tab` pie or header, brush radius `F`, strength `Shift F`, invert while held `Ctrl`, smooth while held `Shift`.
- **Flag puzzle:** a smooth cliff face. Sculpting inward along a faint guide line carves out an "I".
- **Check:** Sim (concept version): a simplified displacement brush on a dense plane, check for depth along the guide. Companion: type the letter.
- **Hints:** Nudge "Follow the crack the waves already started." Specific "Draw brush with Ctrl to carve inward." Answer: exact brush, radius, strength.
- **Manual:** [Sculpting](https://docs.blender.org/manual/en/5.2/sculpt_paint/sculpting/introduction/index.html)

**3. Scatter the guide stones → G**
- **Keys:** Geometry Nodes workspace, add node `Shift A`, connect sockets by dragging, search nodes by typing in the add menu.
- **Flag puzzle:** distribute small glowing stones on a meadow. With the right density and seed, the stones cluster into a "G" seen from above (`Numpad 7`).
- **Check:** Sim (concept version): a simplified node graph with 3 nodes to connect. Companion: type the letter, plus the node count in the tree.
- **Hints:** Nudge "One stone, many places." Specific "Distribute Points on Faces into Instance on Points." Answer: full node graph picture plus values.
- **Manual:** [Geometry Nodes](https://docs.blender.org/manual/en/5.2/modeling/geometry_nodes/introduction.html) · [Distribute Points on Faces](https://docs.blender.org/manual/en/5.2/modeling/geometry_nodes/point/distribute_points_on_faces.html) · [Instance on Points](https://docs.blender.org/manual/en/5.2/modeling/geometry_nodes/instances/instance_on_points.html)

**4. Stage the night scene → N**
- **Keys:** add camera and light `Shift A`, camera view `Numpad 0`, align camera to view `Ctrl Alt Numpad 0`, render image `F12`, Render engine in Properties.
- **Flag puzzle:** the letter "N" is a shadow cast by the lantern frame. It only shows in a final render with the right light placed behind the frame.
- **Check:** Sim (concept version): place a spot light and camera, show a quick shadow preview. Companion: render with `F12`, type the letter.
- **Hints:** Nudge "Shadows need light from behind." Specific "Spot light behind the frame, camera in front." Answer: exact positions.
- **Manual:** [Cameras](https://docs.blender.org/manual/en/5.2/render/cameras.html) · [Lights](https://docs.blender.org/manual/en/5.2/render/lights/light_object.html) · [Render engines](https://docs.blender.org/manual/en/5.2/render/index.html)

**5. Turn the beam → A**
- **Keys:** insert keyframe `I`, play/pause `Space`, jump to start `Shift Left arrow`, Graph Editor, interpolation `T`.
- **Flag puzzle:** keyframe the beam's rotation from 0 to 360 degrees over 120 frames, linear. On frame 60 the beam sweeps across a rock with an "A" on it.
- **Check:** Sim: two keyframes on rotation Z with linear interpolation. Companion: scrub to frame 60, type the letter.
- **Hints:** Nudge "A lighthouse never slows down." Specific "Set interpolation to Linear with T in the Graph Editor." Answer: exact frames and values.
- **Manual:** [Keyframes](https://docs.blender.org/manual/en/5.2/animation/keyframes/introduction.html) · [Graph Editor](https://docs.blender.org/manual/en/5.2/editors/graph_editor/introduction.html)

**6. The lighthouse signal → L (final project)**
- **Build:** combine everything: unwrapped banner, carved cliff, scattered stones, night lighting, and the turning beam. Render a short animation (`Ctrl F12`, or a low-res Eevee preview).
- **Check:** Companion: the app asks for 3 facts (frame count, render engine, number of instanced stones shown in the Spreadsheet editor). Sim: plays a canned version of the scene built from your earlier choices.
- **Finale:** enter SIGNAL. The beam turns, cuts a path into the Fog toward the Squall, and the Old Keeper says "Now they know we're fighting back."
- **Manual:** [Rendering animations](https://docs.blender.org/manual/en/5.2/render/output/index.html)

## 5. Browser simulation: hard keys and fallbacks

**Rule for the sim:** the canvas grabs focus and calls `preventDefault()` on keys it uses. Most keys then work. A few browser shortcuts cannot be blocked at all.

| Blender input | Problem in a browser | Fallback in the sim |
|---|---|---|
| Middle mouse drag | Trackpads have none. Windows middle-click starts autoscroll. | Block autoscroll on middle-button down. Offer Alt + left drag (same as Blender's Emulate 3 Button Mouse). Two-finger trackpad scroll orbits, Shift + scroll pans, pinch or Ctrl + scroll zooms. |
| Numpad 1/3/7/5/0/. | Most laptops have no numpad. | Number row when "Emulate Numpad" is on (mirrors the Blender preference). Clickable navigation gizmo. Backtick pie. |
| Number row 1/2/3 | Clashes with emulated numpad. | Same as Blender: with Emulate Numpad on, select modes move to the header buttons. Show this in a tip. |
| `Ctrl R` (loop cut) | Reloads the page if focus slips. | Block it while the canvas has focus. Add a "leave page?" guard during lessons. Also offer a toolbar button. |
| `Ctrl Tab` (mode pie) | Browser switches tabs. Cannot be blocked. | Mode dropdown in the header. Lessons teach `Tab` first, so this is minor. |
| `Tab` | Moves keyboard focus out of the canvas. | Block it while the canvas has focus. Show a "click the viewport" hint if focus is lost. |
| `Alt` + key (Windows) | Alt alone can focus the browser menu bar (Firefox). | Block Alt keyup while the canvas has focus. |
| `Alt` + drag (Linux) | Some desktops move the whole window. | Offer the gizmo and trackpad options. Note it in settings. |
| `Ctrl Space` (maximize area, not taught) | macOS uses it to switch keyboard input source. | Not used in v1. |
| `Right click` (cancel) | Opens the browser context menu. | Block `contextmenu` on the canvas. |
| `Ctrl W / T / N` | Close tab, new tab, new window. Cannot be blocked. | Never use them in lessons. |
| `Ctrl 1/2/3` (add Subdivision, Tier 2) | Switches browser tabs in most browsers. | Use the Add Modifier button in the sim. Teach `Ctrl 1/2/3` for the companion route only. |
| `Ctrl J` (join, Tier 2) | Opens Downloads in Chrome. | Block while canvas has focus. Also add a Join button. |
| `Ctrl P` (parent, Tier 2) | Opens Print. | Block while canvas has focus (this works reliably). |
| `Ctrl E` (edge menu, Tier 3) | Focuses the address/search bar in some browsers. | Block while canvas has focus. Offer the `U` menu route too. |
| `F12` / `Ctrl F12` (render, Tier 3) | Opens DevTools. | Tier 3 rendering is companion-only. The sim uses a Render button. |
| `Delete` on Mac | Mac keyboards have no forward Delete key. | Teach `X` as the main key, show `fn Delete` as the Mac option. |

**Mac notes for the companion route:** Blender uses `Ctrl`, not `Cmd`, for nearly all of these shortcuts on macOS. Show this once in the Prologue.

## 6. Versions: pinning, updating, and keeping history

### 6a. Which version to pin
- **Decided:** v1 is pinned to **Blender 5.2 LTS** (current LTS as of Nov 2026). A friend downloading Blender today gets 5.2 LTS or 5.3, and the basic keymap is the same in both.
- Manual links always use the versioned path (`/manual/en/5.2/...`), never `/latest/`, so a link never silently changes under a lesson.

### 6b. How lessons stay updatable
- **Keymap file per version:** `data/blender/5.2/keymap.json` maps action ids to keys (for example `"mesh.inset": "I"`). Lessons say "press {mesh.inset}" instead of hard-coding `I`. A keymap change becomes a one-file edit.
- **Links file per version:** `data/blender/5.2/links.json` holds every manual URL. Lessons reference link ids.
- **Generated starter scenes:** each lesson's `.blend` is built by a Python script, `scripts/build_scenes.py`, run with `blender --background --python scripts/build_scenes.py`. For a new Blender version, rerun the script in that version instead of re-saving files by hand.
- **Automated checks (CI):** a link checker for every URL in `links.json`, and a test that every keymap id a lesson uses exists in that version's keymap file.

### 6c. Updating for a new Blender release (checklist)
1. Read the release notes' User Interface and Modeling sections for keymap or tool changes ([release notes index](https://developer.blender.org/docs/release_notes/)).
2. In the new Blender, export the default keymap (Preferences > Keymap > Export) and diff it against the previous one.
3. Copy `data/blender/<old>/` to `data/blender/<new>/`, apply the changes, update link paths.
4. Rebuild starter scenes with the new Blender and replay all six lessons once on each route.
5. Update the "Tested with" badge and changelog.
- **Cadence:** update on each LTS (about every 2 years). For in-between releases, do a quick check only (steps 1 and 2) and fix only if something broke.

### 6d. Keeping historical versions
- Each pinned version lives at its own URL: `/blender/5.2/`, later `/blender/6.2/`. The site's `/blender/` always points to the newest.
- Git tag per version (`blender-lessons-5.2`), so old packs can be rebuilt.
- A version picker in the app: "I'm using Blender ___". It loads that keymap and those links. Unknown versions fall back to the nearest one with a notice.
- Old versions are frozen (no new lessons), but broken links still get fixed.
